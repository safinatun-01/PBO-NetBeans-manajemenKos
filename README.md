# Sistem Manajemen Kos
Aplikasi desktop untuk mengelola data kamar, penghuni, dan pembayaran kos berbasis Java NetBeans dan MySQL.

## Fitur Utama
- Login Admin
- Dashboard Statistik Real-time
- CRUD Kamar, Penghuni, Pembayaran
- Laporan Pembayaran (Filter Bulan/Tahun/Status)
- Ekspor Laporan ke PDF & Excel
- Status Kamar & Penghuni Otomatis

## Teknologi
- Java (NetBeans IDE)
- MySQL (XAMPP)
- JDBC
- Apache PDFBox

## Cara Menjalankan
1. Import database `manajemen_kos.sql` ke MySQL
2. Buka project di NetBeans
3. Jalankan `Main.java`
